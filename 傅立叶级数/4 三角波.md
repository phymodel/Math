# 三角波 Triangle Wave

（傅立叶级数-三角波）设 $f(x)$ 是周期为 $2\pi$ 的周期函数，它在 $[-\pi,\pi]$ 上是一个峰值 $\pm1$、峰位在 $x=\pm\dfrac{\pi}{2}$ 的三角波：

$$
f(x)=
\begin{cases}
-2-\dfrac{2}{\pi}x, & -\pi\le x<-\dfrac{\pi}{2},\\[6pt]
\dfrac{2}{\pi}x, & -\dfrac{\pi}{2}\le x<\dfrac{\pi}{2},\\[6pt]
2-\dfrac{2}{\pi}x, & \dfrac{\pi}{2}\le x<\pi.
\end{cases}
$$

（$f(\pi/2)=1$，$f(0)=f(\pm\pi)=0$，且 $f(-x)=-f(x)$。）将 $f(x)$ 展开成傅立叶级数。

解：由于 $f(-x)=-f(x)$，函数是奇函数(odd)，所以

$$
a_0=a_n=0,
$$

只需算

$$
b_n=\frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\sin nx\,{\rm d}x
$$

被积函数 $f(x)\sin nx$ 是偶函数（奇函数 × 奇函数），所以只算 $[0,\pi]$ 上的积分再乘 2。三角波在 $[0,\pi]$ 上分两段：$[0,\pi/2]$ 上升、$[\pi/2,\pi]$ 下降，所以

$$
b_n=\frac{2}{\pi}\int_0^\pi f(x)\sin nx\,{\rm d}x
=\frac{2}{\pi}\left[\int_0^{\pi/2}\frac{2x}{\pi}\sin nx\,{\rm d}x+\int_{\pi/2}^{\pi}\left(2-\frac{2x}{\pi}\right)\sin nx\,{\rm d}x\right]
$$

两段都要**分部积分**（被积函数是 $x\sin nx$ 型）。

**第一段：**

$$
\int_0^{\pi/2}\frac{2x}{\pi}\sin nx\,{\rm d}x
=\frac{2}{\pi}\left(\left[-\frac{x\cos nx}{n}\right]_0^{\pi/2}+\frac{1}{n}\int_0^{\pi/2}\cos nx\,{\rm d}x\right)
=-\frac{\cos\frac{n\pi}{2}}{n}+\frac{2}{\pi n^2}\sin\frac{n\pi}{2}
$$

**第二段：**

$$
\int_{\pi/2}^{\pi}\sin nx\,{\rm d}x=\left[-\frac{\cos nx}{n}\right]_{\pi/2}^{\pi}=\frac{-\cos n\pi+\cos\frac{n\pi}{2}}{n}
$$

$$
\int_{\pi/2}^{\pi}x\sin nx\,{\rm d}x
=\left[-\frac{x\cos nx}{n}\right]_{\pi/2}^{\pi}+\frac{1}{n}\int_{\pi/2}^{\pi}\cos nx\,{\rm d}x
=\frac{-\pi\cos n\pi+\frac{\pi}{2}\cos\frac{n\pi}{2}}{n}-\frac{\sin\frac{n\pi}{2}}{n^2}
$$

把这两个结果代回（注意第二段带系数 $2-\frac{2x}{\pi}$）：

$$
\int_{\pi/2}^{\pi}\left(2-\frac{2x}{\pi}\right)\sin nx\,{\rm d}x
=\frac{\cos\frac{n\pi}{2}}{n}+\frac{2}{\pi n^2}\sin\frac{n\pi}{2}
$$

两段相加，含 $\cos\frac{n\pi}{2}$ 的项正好抵消：

$$
b_n=\frac{2}{\pi}\left(\frac{4}{\pi n^2}\sin\frac{n\pi}{2}\right)
=\frac{8}{\pi^2 n^2}\sin\frac{n\pi}{2}
$$

也就是

$$
b_n=
\begin{cases}
\dfrac{8(-1)^{k-1}}{\pi^2(2k-1)^2}, & n=2k-1\text{（奇数）}\\[6pt]
0, & n\text{ 为偶数}
\end{cases}
$$

由于

$$
f(x)=\frac{a_0}{2}+\sum_{n=1}^{\infty}(a_n\cos\,nx+b_n\sin\,nx),\,x\in C
$$

即

$$
f(x)=\frac{8}{\pi^2}\sin x-\frac{8}{9\pi^2}\sin 3x+\frac{8}{25\pi^2}\sin 5x-\frac{8}{49\pi^2}\sin 7x+\cdots
=\frac{8}{\pi^2}\sum_{k=1}^{\infty}\frac{(-1)^{k-1}}{(2k-1)^2}\sin(2k-1)x
$$

（自检：在峰点 $x=\dfrac{\pi}{2}$ 处，$\sin\dfrac{(2k-1)\pi}{2}=(-1)^{k-1}$，级数给出 $\dfrac{8}{\pi^2}\sum_{k\ge1}\dfrac{1}{(2k-1)^2}=\dfrac{8}{\pi^2}\cdot\dfrac{\pi^2}{8}=1=f\!\left(\dfrac{\pi}{2}\right)$，对上。）

几点观察：

- 和方波一样**只含奇次谐波**，但系数按 $1/n^2$ 衰减，比方波、锯齿波的 $1/n$ 快得多 —— 因为 $f$ 本身连续，没有跳变。
- 收敛是**绝对且一致**的：$|b_n|\le\dfrac{8}{\pi^2n^2}$，而 $\sum 1/n^2$ 收敛，由 Weierstrass 判别法即得。所以三角波本身没有 Gibbs 现象；同样的 9% 过冲出现在"跳变"处，也就是它的导数（方波）上。
- 系数正负交替 $(-1)^{k-1}$：几何上就是动画里矢量球公转方向的顺逆交替（对比方波全同向）。
- 因为 $1/n^2$ 衰减极快，动画里只取 4 项就已经很接近三角波了；而方波、锯齿波取 4 项还只是"带毛刺的斜线"。

## 设计交互场景

- 实体：3D场景所需的实体。
- 触发系统：3D场景交互所需的触发系统。

### 实体

- TriangleFourierSpheresCircles：傅立叶旋转矢量链。组内 `TriangleSphere[i]`(i=0..3) 与 `TriangleSphere4` 共 5 个节点球
  （y=1.5，半径 0.006，x = −0.5 + (0.4/π)·Σ_{k≤i} (−1)^(k−1)/(2k−1)²，即各阶部分和的端点；
  因为系数按 1/n² 衰减，后几个节点几乎"原地打转"，标尺只有约 0.13 长）；
  `TriangleCircle[i]`(i=0..3) 是 4 个振幅圆（半径 = 128/(π²(2i+1)²)，即系数 8/(π²(2i+1)²) 的 16 倍显示尺度，只取奇次谐波 1/3/5/7），
  圆心落在第 i 个节点上；第 n 个节点绕第 n−1 个节点公转，转 1/3/5/7 圈，方向**顺逆交替** —— 交替正是 (−1)^(k−1) 的几何含义。
- TriangleConnectLine：绿色折线，穿过 TriangleSphere0…TriangleSphere4，把矢量链节点依次连起来（静止时是一条振幅标尺）。
- TriangleConnectLineSine：红色细线，连接链末端 TriangleSphere4 与描点 TriangleSphereSine；其高度即当前部分和。
- TriangleSphereSine：红色小球（r=0.01，起点 (0,1.5,0)），链条末端的“画笔”，沿 TriangleSineY 行走，把部分和画成波形。
- TriangleSineY：x=0 的竖直参数曲线，opacity 0（不可见），仅作 MoveAlong 的轨迹模板，不参与显示。
- TriangleSineWave：可见波形，x=10t，y=(128/π²)(sin t − sin3t/9 + sin5t/25 − sin7t/49)，即三角波的 4 项部分和曲线
  （只叠 1、3、5、7 次，偶次项不出现）；触发时由 EntityMesh 扫相位重绘。
- TriangleTextRun：“运行”按钮（Text，kinematic），初始显示，点击后隐藏并启动整段动画。
- TriangleTextBack：“返回”按钮（Text，kinematic），始终显示，点击后回到《1 傅立叶级数.md》。

```phymodel

Group(name: "TriangleFourierSpheresCircles", position: (0, 0, 0)) {
    Repeat(4) { i in
        CAD()
        .name("TriangleSphere[i]")
        .mesh(commands: [
            "DEF sphere = SOLID_FORMULA 0,0,0 (x/0.006)^2+(y/0.006)^2+(z/0.006)^2-1=0",
        ])
        .material(red: 0.67, green: 0.32, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
        .position(x: -0.5 + 0.4/pi * ((i >= 1 ? 1 : 0) + (i >= 2 ? -1/9 : 0) + (i >= 3 ? 1/25 : 0)), y: 1.5, z: 0.0)
    }
    CAD()
    .name("TriangleSphere4")
    .mesh(commands: [
        "DEF sphere = SOLID_FORMULA 0,0,0 (x/0.006)^2+(y/0.006)^2+(z/0.006)^2-1=0",
    ])
    .material(red: 0.67, green: 0.32, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
    .position(x: -0.5 + 0.4/pi * (1 - 1/9 + 1/25 - 1/49), y: 1.5, z: 0.0)
    .trail(style: .line, lifeSpan: 3.0, size: 0.002, color: [1.0, 0.4, 0.2], opacity: 0.8)
    Repeat(4) { i in
        Graph()
        .name("TriangleCircle[i]")
        .mesh(x: "128/(pi*pi*(2*i+1)*(2*i+1))*cos(t)", y: "128/(pi*pi*(2*i+1)*(2*i+1))*sin(t)", z: "0", t: "[0,2*pi]", radius: 0.002)
        .material(red: 0.46, green: 0.2, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
        .position(x: -0.5 + 0.4/pi * ((i >= 1 ? 1 : 0) + (i >= 2 ? -1/9 : 0) + (i >= 3 ? 1/25 : 0)), y: 1.5, z: 0.0)
    }
}

Line()
.name("TriangleConnectLine")
.mesh(radius: 0.002, through: ["TriangleSphere0", "TriangleSphere1", "TriangleSphere2", "TriangleSphere3", "TriangleSphere4"])
.material(red: 0.1, green: 0.9, blue: 0.1, opacity: 1, roughness: 0.5, metallic: 0.8)

Line()
.name("TriangleConnectLineSine")
.mesh(radius: 0.002, through: ["TriangleSphere4", "TriangleSphereSine"])
.material(red: 0.8, green: 0.1, blue: 0.1, opacity: 1.0, roughness: 0.5, metallic: 0.8)

CAD()
.name("TriangleSphereSine")
.mesh(commands: [
    "DEF sphere = SOLID_FORMULA 0,0,0 (x/0.01)^2+(y/0.01)^2+(z/0.01)^2-1=0",
])
.material(red: 0.9, green: 0.1, blue: 0.1, opacity: 1, roughness: 0.5, metallic: 0.8)
.position(x: 0, y: 1.5, z: 0.0)

Graph()
.name("TriangleSineY")
.mesh(x: "0", y: "(128/(pi*pi))*(sin(t)-sin(3*t)/9+sin(5*t)/25-sin(7*t)/49)", z: "0", t: "[0,2*pi]", radius: 0.005)
.material(red: 0.46, green: 0.2, blue: 1.0, opacity: 0.0, roughness: 0.5, metallic: 0.8)
.position(x: 0.0, y: 1.5, z: 0.0)

Graph()
.name("TriangleSineWave")
.mesh(x: "10t", y: "(128/(pi*pi))*(sin(t)-sin(3*t)/9+sin(5*t)/25-sin(7*t)/49)", z: "0", t: "[0,2*pi]", radius: 0.005)
.material(red: 0.46, green: 0.2, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
.position(x: 0.0, y: 1.5, z: 0.0)

Text()
.name("TriangleTextRun")
.mesh(text: "运行", extrusionDepth: 0.02, fontSize: 0.1)
.physic(mass: 0.1, staticFriction: 0.9, dynamicFriction: 0.75, restitution: 0.22, mode: .kinematic)
.material(red: 0.2, green: 0.8, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
.position(x: -0.2, y: 1.7, z: 0.0)

Text()
.name("TriangleTextBack")
.mesh(text: "返回", extrusionDepth: 0.02, fontSize: 0.1)
.physic(mass: 0.1, staticFriction: 0.9, dynamicFriction: 0.75, restitution: 0.22, mode: .kinematic)
.material(red: 0.2, green: 0.8, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
.position(x: 0.2, y: 1.7, z: 0.0)

```

### 触发系统

```phymodel

Behavior()
.name("tap_TriangleTextRun")
.trigger{
    Tap(){
        objects: ["TriangleTextRun"]
    }
}
.actions{

    Hide(0){
        objects: ["TriangleTextRun"]
        motionType: .scale
        duration: 0.5
    }
    // ---------- id=1：播放前瞬时复位（并行） ----------
    //   范围选择 + index：等价于原来的 9 个逐球 Transform，公式与 Group 内 .position(...) 同源
    //   （duration=0 时 translation 是绝对位姿，故必须与声明位置保持一致）
    Transform(1){
        objects: ["TriangleSphere[0..4]"],
        translation: [-0.5 + 0.4/pi * ((index >= 1 ? 1 : 0) + (index >= 2 ? -1/9 : 0) + (index >= 3 ? 1/25 : 0) + (index >= 4 ? -1/49 : 0)), 1.5, 0.0],
        duration: 0
    }
    Transform(1){
        objects: ["TriangleCircle[0..3]"],
        translation: [-0.5 + 0.4/pi * ((index >= 1 ? 1 : 0) + (index >= 2 ? -1/9 : 0) + (index >= 3 ? 1/25 : 0) + (index >= 4 ? -1/49 : 0)), 1.5, 0.0],
        duration: 0
    }

    // ---------- id=2：动画（并行） ----------
    Orbit(2){
        objects: ["TriangleSphere1, TriangleCircle1"],
        center: "TriangleSphere0",
        angle: 90,
        alignPath: false,
        clockwise: true,
        revolutions: 1,
        duration: 12
    }
    Orbit(2){
        objects: ["TriangleSphere2, TriangleCircle2"],
        center: "TriangleSphere1",
        angle: 90,
        alignPath: false,
        clockwise: false,
        revolutions: 3,
        duration: 12
    }
    Orbit(2){
        objects: ["TriangleSphere3, TriangleCircle3"],
        center: "TriangleSphere2",
        angle: 90,
        alignPath: false,
        clockwise: true,
        revolutions: 5,
        duration: 12
    }
    Orbit(2){
        objects: ["TriangleSphere4"],
        center: "TriangleSphere3",
        angle: 90,
        alignPath: false,
        clockwise: false,
        revolutions: 7,
        duration: 12
    }
    MoveAlong(2){
        objects: ["TriangleSphereSine"],
        path: "TriangleSineY",
        tStart: 2*pi,
        tEnd: 0.0,
        alignPath: false,
        clockwise: false,
        iterations: 1,
        duration: 12.0
    }
    EntityMesh(2){
        objects: "TriangleSineWave",
        y: "(128/(pi*pi))*(sin(t+phase)-sin(3*(t+phase))/9+sin(5*(t+phase))/25-sin(7*(t+phase))/49)",
        phase: "[2*pi, 0]",
        duration: 12.0
    }
    Show(3){
        objects: ["TriangleTextRun"]
        motionType: .pop
        duration: 0.5
    }
}

Behavior()
.name("tap_TriangleTextBack")
.trigger{
    Tap(){
        objects: ["TriangleTextBack"]
    }
}
.actions{
    Emphasize(1){
        objects: ["TriangleTextBack"]
        motionType: .pop
        duration: 0.4
    }
    Speak(2){
        object: "TriangleTextBack"
        text: "返回傅立叶级数。"
    }
    OpenScene(3){
        scene: "1 傅立叶级数.md"
        duration: 0
    }
}
```
