# 方波 Square Wave

（傅立叶级数-方波）设 $f(x)$ 是周期为 $2\pi$ 的周期函数，它在 $[-\pi,\pi]$ 上的表达式为

$$
f(x)=
\begin{cases}
-1,&-\pi\le x<0,\\
1,&0\le x<\pi.
\end{cases}
$$

将 $f(x)$ 展开成傅立叶级数。

解：由于 $f(-x)=-f(x)$（等价地 $f(2\pi-x)=-f(x)$），函数是奇函数(odd)，所以

$$
a_0=a_n=0,
$$

只需算

$$
b_n=\frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\sin nx\,{\rm d}x
$$

因为 $f(x)$ 是奇函数，$\sin nx$ 是奇函数，奇函数乘奇函数为偶函数，被积函数 $f(x)\sin nx$ 是偶函数，所以

$$
b_n=\frac{2}{\pi}\int_0^\pi f(x)\sin nx\,{\rm d}x=\frac{2}{\pi}\int_0^\pi 1\cdot\sin nx\,{\rm d}x
=\frac{2}{\pi}\left[-\frac{\cos nx}{n}\right]_0^\pi
=\frac{2}{n\pi}\bigl(1-\cos n\pi\bigr)
=\frac{2}{n\pi}\bigl(1-(-1)^n\bigr)
$$

（这一步只是基本积分公式 $\int\sin nx\,{\rm d}x=-\dfrac{\cos nx}{n}$，**不需要分部积分** —— 方波的被积函数是"常数 × $\sin nx$"；只有当被积函数里出现 $x\sin nx$ 时才需要分部积分，例如锯齿波和三角波。）

也就是

$$
b_n=
\begin{cases}
\dfrac{4}{n\pi}, & n\text{ 为奇数}\\[6pt]
0, & n\text{ 为偶数}
\end{cases}
$$

令 $n=2k-1$，即 $b_{2k-1}=\dfrac{4}{(2k-1)\pi}$。由于

$$
f(x)=\frac{a_0}{2}+\sum_{n=1}^{\infty}(a_n\cos\,nx+b_n\sin\,nx),\,x\in C
$$

即

$$
f(x)=\frac{4}{\pi}\sin x+\frac{4}{3\pi}\sin 3x+\frac{4}{5\pi}\sin 5x+\cdots+\frac{4}{(2k-1)\pi}\sin(2k-1)x+\cdots
$$

几点观察：

- 偶次谐波**整体缺席**（$b_2=b_4=\cdots=0$）：只保留 $1,3,5,7,\cdots$ 次项，这正是 $1-(-1)^n$ 的直接结果。
- 系数按 $1/n$ 衰减，与锯齿波同阶，收敛较慢；跳变越"硬"，高频项就越多。
- 在间断点 $x=0,\pm\pi$ 处级数收敛到左右极限的平均值 $\dfrac{-1+1}{2}=0$，这些点不在 $C$ 中 —— 所以 $C$ 只是"连续点集"。
- 跳变附近出现 **Gibbs 现象**：任意有限项部分和在跳变处都会过冲约 9%，动画里看 4 项部分和的"方角"，这个毛刺很明显。

## 设计交互场景

- 实体：3D场景所需的实体。
- 触发系统：3D场景交互所需的触发系统。

### 实体

- SquareFourierSpheresCircles：傅立叶旋转矢量链。组内 `SquareSphere[i]`(i=0..3) 与 `SquareSphere4` 共 5 个节点球
  （y=1.5，半径 0.006，x = −0.5 + (0.4/π)·Σ_{k≤i} 1/(2k−1)，即各阶部分和的端点；因为 b_n 恒正，节点只单向右移，
  不像锯齿波那样左右来回）；
  `SquareCircle[i]`(i=0..3) 是 4 个振幅圆（半径 ∝ 4/(π(2i+1))，只对应奇次谐波 1/3/5/7），圆心落在第 i 个节点上，
  第 n 个节点绕第 n−1 个节点公转，转 1/3/5/7 圈且方向**全部相同** —— 方波所有系数同号，
  没有锯齿波那种 (−1)^(n+1) 导致的顺逆交替。
- SquareConnectLine：绿色折线，穿过 SquareSphere0…SquareSphere4，把矢量链节点依次连起来（静止时是一条振幅标尺）。
- SquareConnectLineSine：红色细线，连接链末端 SquareSphere4 与描点 SquareSphereSine；其高度即当前部分和。
- SquareSphereSine：红色小球（r=0.01，起点 (0,1.5,0)），链条末端的“画笔”，沿 SquareSineY 行走，把部分和画成波形。
- SquareSineY：x=0 的竖直参数曲线，opacity 0（不可见），仅作 MoveAlong 的轨迹模板，不参与显示。
- SquareSineWave：可见波形，x=10t，y=(40/π)(sin t + sin3t/3 + sin5t/5 + sin7t/7)，即方波的 4 项部分和曲线
  （只叠 1、3、5、7 次，偶次项不出现）；触发时由 EntityMesh 扫相位重绘。
- SquareTextRun：“运行”按钮（Text，kinematic），初始显示，点击后隐藏并启动整段动画。
- SquareTextBack：“返回”按钮（Text，kinematic），始终显示，点击后回到《1 傅立叶级数.md》。

```phymodel

Group(name: "SquareFourierSpheresCircles", position: (0, 0, 0)) {
    Repeat(4) { i in
        CAD()
        .name("SquareSphere[i]")
        .mesh(commands: [
            "DEF sphere = SOLID_FORMULA 0,0,0 (x/0.006)^2+(y/0.006)^2+(z/0.006)^2-1=0",
        ])
        .material(red: 0.67, green: 0.32, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
        .position(x: -0.5 + 0.4/pi * ((i >= 1 ? 1 : 0) + (i >= 2 ? 1/3 : 0) + (i >= 3 ? 1/5 : 0) + (i >= 4 ? 1/7 : 0)), y: 1.5, z: 0.0)
    }
    CAD()
    .name("SquareSphere4")
    .mesh(commands: [
        "DEF sphere = SOLID_FORMULA 0,0,0 (x/0.006)^2+(y/0.006)^2+(z/0.006)^2-1=0",
    ])
    .material(red: 0.67, green: 0.32, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
    .position(x: -0.5 + 0.4/pi * (1 + 1/3 + 1/5 + 1/7), y: 1.5, z: 0.0)
    .trail(style: .line, lifeSpan: 3.0, size: 0.002, color: [1.0, 0.4, 0.2], opacity: 0.8)
    Repeat(4) { i in
        Graph()
        .name("SquareCircle[i]")
        .mesh(x: "40/(pi*(2*i+1))*cos(t)", y: "40/(pi*(2*i+1))*sin(t)", z: "0", t: "[0,2*pi]", radius: 0.002)
        .material(red: 0.46, green: 0.2, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
        .position(x: -0.5 + 0.4/pi * ((i >= 1 ? 1 : 0) + (i >= 2 ? 1/3 : 0) + (i >= 3 ? 1/5 : 0)), y: 1.5, z: 0.0)
    }
}

Line()
.name("SquareConnectLine")
.mesh(radius: 0.002, through: ["SquareSphere0", "SquareSphere1", "SquareSphere2", "SquareSphere3", "SquareSphere4"])
.material(red: 0.1, green: 0.9, blue: 0.1, opacity: 1, roughness: 0.5, metallic: 0.8)

Line()
.name("SquareConnectLineSine")
.mesh(radius: 0.002, through: ["SquareSphere4", "SquareSphereSine"])
.material(red: 0.8, green: 0.1, blue: 0.1, opacity: 1.0, roughness: 0.5, metallic: 0.8)

CAD()
.name("SquareSphereSine")
.mesh(commands: [
    "DEF sphere = SOLID_FORMULA 0,0,0 (x/0.01)^2+(y/0.01)^2+(z/0.01)^2-1=0",
])
.material(red: 0.9, green: 0.1, blue: 0.1, opacity: 1, roughness: 0.5, metallic: 0.8)
.position(x: 0, y: 1.5, z: 0.0)

Graph()
.name("SquareSineY")
.mesh(x: "0", y: "(40/pi)*(sin(t)+sin(3*t)/3+sin(5*t)/5+sin(7*t)/7)", z: "0", t: "[0,2*pi]", radius: 0.005)
.material(red: 0.46, green: 0.2, blue: 1.0, opacity: 0.0, roughness: 0.5, metallic: 0.8)
.position(x: 0.0, y: 1.5, z: 0.0)

Graph()
.name("SquareSineWave")
.mesh(x: "10t", y: "(40/pi)*(sin(t)+sin(3*t)/3+sin(5*t)/5+sin(7*t)/7)", z: "0", t: "[0,2*pi]", radius: 0.005)
.material(red: 0.46, green: 0.2, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
.position(x: 0.0, y: 1.5, z: 0.0)

Text()
.name("SquareTextRun")
.mesh(text: "运行", extrusionDepth: 0.02, fontSize: 0.1)
.physic(mass: 0.1, staticFriction: 0.9, dynamicFriction: 0.75, restitution: 0.22, mode: .kinematic)
.material(red: 0.2, green: 0.8, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
.position(x: -0.2, y: 1.7, z: 0.0)

Text()
.name("SquareTextBack")
.mesh(text: "返回", extrusionDepth: 0.02, fontSize: 0.1)
.physic(mass: 0.1, staticFriction: 0.9, dynamicFriction: 0.75, restitution: 0.22, mode: .kinematic)
.material(red: 0.2, green: 0.8, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
.position(x: 0.2, y: 1.7, z: 0.0)

```

### 触发系统

```phymodel

Behavior()
.name("tap_SquareTextRun")
.trigger{
    Tap(){
        objects: ["SquareTextRun"]
    }
}
.actions{

    Hide(0){
        objects: ["SquareTextRun"]
        motionType: .scale
        duration: 0.5
    }
    // ---------- id=1：播放前瞬时复位（并行） ----------
    //   范围选择 + index：等价于原来的 9 个逐球 Transform，公式与 Group 内 .position(...) 同源
    //   （duration=0 时 translation 是绝对位姿，故必须与声明位置保持一致）
    Transform(1){
        objects: ["SquareSphere[0..4]"],
        translation: [-0.5 + 0.4/pi * ((index >= 1 ? 1 : 0) + (index >= 2 ? 1/3 : 0) + (index >= 3 ? 1/5 : 0) + (index >= 4 ? 1/7 : 0)), 1.5, 0.0],
        duration: 0
    }
    Transform(1){
        objects: ["SquareCircle[0..3]"],
        translation: [-0.5 + 0.4/pi * ((index >= 1 ? 1 : 0) + (index >= 2 ? 1/3 : 0) + (index >= 3 ? 1/5 : 0) + (index >= 4 ? 1/7 : 0)), 1.5, 0.0],
        duration: 0
    }

    // ---------- id=2：动画（并行） ----------
    Orbit(2){
        objects: ["SquareSphere1, SquareCircle1"],
        center: "SquareSphere0",
        angle: 90,
        alignPath: false,
        clockwise: true,
        revolutions: 1,
        duration: 12
    }
    Orbit(2){
        objects: ["SquareSphere2, SquareCircle2"],
        center: "SquareSphere1",
        angle: 90,
        alignPath: false,
        clockwise: true,
        revolutions: 3,
        duration: 12
    }
    Orbit(2){
        objects: ["SquareSphere3, SquareCircle3"],
        center: "SquareSphere2",
        angle: 90,
        alignPath: false,
        clockwise: true,
        revolutions: 5,
        duration: 12
    }
    Orbit(2){
        objects: ["SquareSphere4"],
        center: "SquareSphere3",
        angle: 90,
        alignPath: false,
        clockwise: true,
        revolutions: 7,
        duration: 12
    }
    MoveAlong(2){
        objects: ["SquareSphereSine"],
        path: "SquareSineY",
        tStart: 2*pi,
        tEnd: 0.0,
        alignPath: false,
        clockwise: false,
        iterations: 1,
        duration: 12.0
    }
    EntityMesh(2){
        objects: "SquareSineWave",
        y: "(40/pi)*(sin(t+phase)+sin(3*(t+phase))/3+sin(5*(t+phase))/5+sin(7*(t+phase))/7)",
        phase: "[2*pi, 0]",
        duration: 12.0
    }
    Show(3){
        objects: ["SquareTextRun"]
        motionType: .pop
        duration: 0.5
    }
}

Behavior()
.name("tap_SquareTextBack")
.trigger{
    Tap(){
        objects: ["SquareTextBack"]
    }
}
.actions{
    Emphasize(1){
        objects: ["SquareTextBack"]
        motionType: .pop
        duration: 0.4
    }
    Speak(2){
        object: "SquareTextBack"
        text: "返回傅立叶级数。"
    }
    OpenScene(3){
        scene: "1 傅立叶级数.md"
        duration: 0
    }
}

```
