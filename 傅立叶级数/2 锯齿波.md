# 锯齿波 Sawtooth Wave

（傅立叶级数-锯齿波）设 $f(x)$ 是周期为 $2\pi$ 的周期函数，它在 $[-\pi,\pi]$ 上的表达式为 

$$
f(x)=\frac{1}{\pi}x,\,\,-\pi\le x<\pi.
$$

将 $f(x)$ 展开成傅立叶级数。

解：由于 $f(x)=-f(-x)$，函数是奇数(odd)，所以 

$$
a_0=a_n=0,
$$

只需算

$$
b_n=\frac{1}{\pi}\int_{-\pi}^{\pi}\frac{x}{\pi}\sin nx\,dx
$$

因为 $x$ 是奇函数，$\sin nx$ 是奇函数，奇函数乘奇函数为偶函数，被积函数 $\dfrac{x}{\pi}\sin nx$ 是偶函数，所以

$$
b_n=\frac{2}{\pi}\int_0^\pi \frac{x}{\pi}\sin nx\,dx
=\frac{2}{\pi^2}\int_0^\pi x\sin nx\,dx
$$

根据分部积分，有

$$
\int_0^\pi x\sin nx\,dx
=\left[-\frac{x\cos nx}{n}\right]_0^\pi+\frac{1}{n}\int_0^\pi \cos nx\,dx
=-\frac{\pi\cos n\pi}{n}+0
=-\frac{\pi(-1)^n}{n}
$$

所以

$$
b_n=\frac{2}{\pi^2}\left(-\frac{\pi(-1)^n}{n}\right)
=-\frac{2(-1)^n}{\pi n}
=\frac{2(-1)^{n+1}}{\pi n}
$$

也就是

$$
b_n=
\begin{cases}
\dfrac{2}{\pi n}, & n\text{ 为奇数}\\[6pt]
-\dfrac{2}{\pi n}, & n\text{ 为偶数}
\end{cases}
$$

由于 

$$
f(x)=\frac{a_0}{2}+\sum_{n=1}^{\infty}(a_n\cos\,nx+b_n\sin\,nx),\,x\in C
$$

即

$$
f(x)=\frac{2}{\pi}\sin x
-\frac{2}{2\pi}\sin 2x
+\frac{2}{3\pi}\sin 3x
-\frac{2}{4\pi}\sin 4x
+\frac{2}{5\pi}\sin 5x-\cdots
$$


## 设计交互场景

- 实体：3D场景所需的实体。
- 触发系统：3D场景交互所需的触发系统。

### 实体

- SawtoothFourierSpheresCircles：傅立叶旋转矢量链。组内 `SawtoothSphere[i]`(i=0..3) 与 `SawtoothSphere4` 共 5 个节点球
  （y=1.5，半径 0.006，x = −0.5 + (0.4/π)·Σ_{k≤i}(−1)^(k+1)/k，即各阶部分和的端点）；
  `SawtoothCircle[i]`(i=0..3) 是 4 个振幅圆（半径 ∝ 2/(πn)，n=i+1），圆心落在第 i 个节点上，
  第 n 个节点绕第 n−1 个节点公转，转 1/2/3/4 圈且方向交替 —— 交替正是 (−1)^(n+1) 的几何含义。
- SawtoothConnectLine：绿色折线，穿过 SawtoothSphere0…SawtoothSphere4，把矢量链节点依次连起来（静止时是一条振幅标尺）。
- SawtoothConnectLineSine：红色细线，连接链末端 SawtoothSphere4 与描点 SawtoothSphereSine；其高度即当前部分和。
- SawtoothSphereSine：红色小球（r=0.01，起点 (0,1.5,0)），链条末端的“画笔”，沿 SawtoothSineY 行走，把部分和画成波形。
- SawtoothSineY：x=0 的竖直参数曲线，opacity 0（不可见），仅作 MoveAlong 的轨迹模板，不参与显示。
- SawtoothSineXY：可见波形，x=10t，y=(40/π)(sin t − sin2t/2 + sin3t/3 − sin4t/4)，即锯齿波的 4 项部分和曲线；
  触发时由 EntityMesh 扫相位重绘。
- SawtoothTextRun：“运行”按钮（Text，kinematic），初始显示，点击后隐藏并启动整段动画。
- SawtoothTextBack：“返回”按钮（Text，kinematic），始终显示，点击后回到《1 傅立叶级数.md》。

```phymodel

Group(name: "SawtoothFourierSpheresCircles", position: (0, 0, 0)) {
    Repeat(4) { i in
        CAD()
        .name("SawtoothSphere[i]")
        .mesh(commands: [
            "DEF sphere = SOLID_FORMULA 0,0,0 (x/0.006)^2+(y/0.006)^2+(z/0.006)^2-1=0",
        ])
        .material(red: 0.67, green: 0.32, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
        .position(x: -0.5 + 0.4/pi * ((i >= 1 ? 1 : 0) + (i >= 2 ? -1/2 : 0) + (i >= 3 ? 1/3 : 0) + (i >= 4 ? -1/4 : 0)), y: 1.5, z: 0.0)
    }
    CAD()
    .name("SawtoothSphere4")
    .mesh(commands: [
        "DEF sphere = SOLID_FORMULA 0,0,0 (x/0.006)^2+(y/0.006)^2+(z/0.006)^2-1=0",
    ])
    .material(red: 0.67, green: 0.32, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
    .position(x: -0.5 + 0.4/pi * (1 - 1/2 + 1/3 - 1/4), y: 1.5, z: 0.0)
    .trail(style: .line, lifeSpan: 3.0, size: 0.002, color: [1.0, 0.4, 0.2], opacity: 0.8)
    Repeat(4) { i in
        Graph()
        .name("SawtoothCircle[i]")
        .mesh(x: "4/(pi*(i+1))*10*cos(t)", y: "4/(pi*(i+1))*10*sin(t)", z: "0", t: "[0,2*pi]", radius: 0.002)
        .material(red: 0.46, green: 0.2, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
        .position(x: -0.5 + 0.4/pi * ((i >= 1 ? 1 : 0) + (i >= 2 ? -1/2 : 0) + (i >= 3 ? 1/3 : 0)), y: 1.5, z: 0.0)
    }
}

Line()
.name("SawtoothConnectLine")
.mesh(radius: 0.002, through: ["SawtoothSphere0", "SawtoothSphere1", "SawtoothSphere2", "SawtoothSphere3", "SawtoothSphere4"])
.material(red: 0.1, green: 0.9, blue: 0.1, opacity: 1, roughness: 0.5, metallic: 0.8)

Line()
.name("SawtoothConnectLineSine")
.mesh(radius: 0.002, through: ["SawtoothSphere4", "SawtoothSphereSine"])
.material(red: 0.8, green: 0.1, blue: 0.1, opacity: 1.0, roughness: 0.5, metallic: 0.8)

CAD()
.name("SawtoothSphereSine")
.mesh(commands: [
    "DEF sphere = SOLID_FORMULA 0,0,0 (x/0.01)^2+(y/0.01)^2+(z/0.01)^2-1=0",
])
.material(red: 0.9, green: 0.1, blue: 0.1, opacity: 1, roughness: 0.5, metallic: 0.8)
.position(x: 0, y: 1.5, z: 0.0)

Graph()
.name("SawtoothSineY")
.mesh(x: "0", y: "(40/pi)*(sin(t)-sin(2*t)/2+sin(3*t)/3-sin(4*t)/4)", z: "0", t: "[0,2*pi]", radius: 0.005)
.material(red: 0.46, green: 0.2, blue: 1.0, opacity: 0.0, roughness: 0.5, metallic: 0.8)
.position(x: 0.0, y: 1.5, z: 0.0)

Graph()
.name("SawtoothSineXY")
.mesh(x: "10t", y: "(40/pi)*(sin(t)-sin(2*t)/2+sin(3*t)/3-sin(4*t)/4)", z: "0", t: "[0,2*pi]", radius: 0.005)
.material(red: 0.46, green: 0.2, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
.position(x: 0.0, y: 1.5, z: 0.0)

Text()
.name("SawtoothTextRun")
.mesh(text: "运行", extrusionDepth: 0.02, fontSize: 0.1)
.physic(mass: 0.1, staticFriction: 0.9, dynamicFriction: 0.75, restitution: 0.22, mode: .kinematic)
.material(red: 0.2, green: 0.8, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
.position(x: -0.2, y: 1.7, z: 0.0)

Text()
.name("SawtoothTextBack")
.mesh(text: "返回", extrusionDepth: 0.02, fontSize: 0.1)
.physic(mass: 0.1, staticFriction: 0.9, dynamicFriction: 0.75, restitution: 0.22, mode: .kinematic)
.material(red: 0.2, green: 0.8, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
.position(x: 0.2, y: 1.7, z: 0.0)

```

### 触发系统

```phymodel

Behavior()
.name("tap_SawtoothTextRun")
.trigger{
    Tap(){
        objects: ["SawtoothTextRun"]
    }
}
.actions{

    Hide(0){
        objects: ["SawtoothTextRun"]
        motionType: .scale
        duration: 0.5
    }
    // ---------- id=1：播放前瞬时复位（并行） ----------
    //   范围选择 + index：等价于原来的 9 个逐球 Transform，公式与 Group 内 .position(...) 同源
    //   （duration=0 时 translation 是绝对位姿，故必须与声明位置保持一致）
    Transform(1){
        objects: ["SawtoothSphere[0..4]"],
        translation: [-0.5 + 0.4/pi * ((index >= 1 ? 1 : 0) + (index >= 2 ? -1/2 : 0) + (index >= 3 ? 1/3 : 0) + (index >= 4 ? -1/4 : 0)), 1.5, 0.0],
        duration: 0
    }
    Transform(1){
        objects: ["SawtoothCircle[0..3]"],
        translation: [-0.5 + 0.4/pi * ((index >= 1 ? 1 : 0) + (index >= 2 ? -1/2 : 0) + (index >= 3 ? 1/3 : 0) + (index >= 4 ? -1/4 : 0)), 1.5, 0.0],
        duration: 0
    }

    // ---------- id=2：动画（并行） ----------
    Orbit(2){
        objects: ["SawtoothSphere1, SawtoothCircle1"],
        center: "SawtoothSphere0",
        angle: 90,
        alignPath: false,
        clockwise: true,
        revolutions: 1,
        duration: 12
    }
    Orbit(2){
        objects: ["SawtoothSphere2, SawtoothCircle2"],
        center: "SawtoothSphere1",
        angle: 90,
        alignPath: false,
        clockwise: false,
        revolutions: 2,
        duration: 12
    }
    Orbit(2){
        objects: ["SawtoothSphere3, SawtoothCircle3"],
        center: "SawtoothSphere2",
        angle: 90,
        alignPath: false,
        clockwise: true,
        revolutions: 3,
        duration: 12
    }
    Orbit(2){
        objects: ["SawtoothSphere4"],
        center: "SawtoothSphere3",
        angle: 90,
        alignPath: false,
        clockwise: false,
        revolutions: 4,
        duration: 12
    }
    MoveAlong(2){
        objects: ["SawtoothSphereSine"],
        path: "SawtoothSineY",
        tStart: 2*pi,
        tEnd: 0.0,
        alignPath: false,
        clockwise: false,
        iterations: 1,
        duration: 12.0
    }
    EntityMesh(2){
        objects: "SawtoothSineXY",
        y: "(40/pi)*(sin(t+phase)-sin(2*(t+phase))/2+sin(3*(t+phase))/3-sin(4*(t+phase))/4)",
        phase: "[2*pi, 0]",
        duration: 12.0
    }
    Show(3){
        objects: ["SawtoothTextRun"]
        motionType: .pop
        duration: 0.5
    }
}

Behavior()
.name("tap_SawtoothTextBack")
.trigger{
    Tap(){
        objects: ["SawtoothTextBack"]
    }
}
.actions{
    Emphasize(1){
        objects: ["SawtoothTextBack"]
        motionType: .pop
        duration: 0.4
    }
    Speak(2){
        object: "SawtoothTextBack"
        text: "返回傅立叶级数。"
    }
    OpenScene(3){
        scene: "1 傅立叶级数.md"
        duration: 0
    }
}

```
