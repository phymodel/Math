# 脉冲波 Pulse Wave

（傅立叶级数-脉冲波）设 $f(x)$ 是周期为 $2\pi$ 的周期函数，它在 $[-\pi,\pi]$ 上是一个宽度 $\varepsilon$、高度 $1/\varepsilon$ 的窄矩形脉冲：

$$
f(x)=
\begin{cases}
\dfrac{1}{\varepsilon},&|x|<\dfrac{\varepsilon}{2},\\[6pt]
0,&\text{其他}.
\end{cases}
$$

（高度取 $1/\varepsilon$ 是为了让脉冲**面积恒等于 1**：$\int_{-\pi}^{\pi}f\,{\rm d}x=1$。$\varepsilon\to0$ 时它趋于 $\delta$ 函数。）

将 $f(x)$ 展开成傅立叶级数。

解：矩形脉冲是**偶函数**，所以 $b_n=0$，只需算 $a_0$ 和 $a_n$。

$$
a_0=\frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\,{\rm d}x=\frac{1}{\pi}\cdot 1=\frac{1}{\pi}
$$

$$
a_n=\frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\cos nx\,{\rm d}x
=\frac{2}{\pi}\int_0^{\varepsilon/2}\frac{1}{\varepsilon}\cos nx\,{\rm d}x
=\frac{2}{n\pi\varepsilon}\sin\frac{n\varepsilon}{2},\qquad n\ge1
$$

把它写成"包络 × 抽样函数"的形式更清楚：

$$
a_n=\frac{1}{\pi}\cdot\frac{\sin\frac{n\varepsilon}{2}}{\frac{n\varepsilon}{2}}
$$

由于

$$
f(x)=\frac{a_0}{2}+\sum_{n=1}^{\infty}(a_n\cos\,nx+b_n\sin\,nx),\,x\in C
$$

即

$$
f(x)=\frac{1}{2\pi}+\frac{1}{\pi}\sum_{n=1}^{\infty}\frac{\sin\frac{n\varepsilon}{2}}{\frac{n\varepsilon}{2}}\cos nx
$$

**关键一步：让 $\varepsilon\to0$。** 对任意固定的 $n$，由 $\lim\limits_{t\to0}\dfrac{\sin t}{t}=1$ 得

$$
a_n\longrightarrow\frac{1}{\pi}\qquad(n=1,2,3,\cdots)
$$

也就是**所有谐波的权重都趋于同一个值 $1/\pi$** —— 这就是**等幅谱**。

- 对比：方波、锯齿波的系数按 $1/n$ 衰减，三角波按 $1/n^2$ 衰减；脉冲**不衰减**，高低频一视同仁。
- 物理含义：**时域越窄，频域越宽**。脉冲宽 $\varepsilon$ 时，$n\lesssim 1/\varepsilon$ 的谐波权重几乎都是 $1/\pi$，一直到 $n=\dfrac{2\pi}{\varepsilon}$ 才出现第一个零点。
- 代价：$\varepsilon\to0$ 的极限对象已经**不是普通函数**（而是周期冲激串），所以级数

$$
\frac{1}{2\pi}+\frac{1}{\pi}\sum_{n=1}^{\infty}\cos nx
$$

在通常意义下处处不收敛，只能按分布意义（或只看部分和）理解。它的部分和就是狄利克雷核的一半，在 $x=0$ 附近堆出一个高度 $\approx N/\pi$ 的尖峰。

**场景画的是它的正弦（奇对称）版本。** 动画里的 8 个矢量球初始都沿 $+x$ 方向排开，矢链末端描出的是正弦级数

$$
\frac{1}{\pi}\sum_{n=1}^{\infty}\sin nx=\frac{1}{2\pi}\cot\frac{x}{2}\qquad(\text{Abel 求和 / 主值意义})
$$

它的频率成分与上面的余弦版本**完全一样**（每一项都是等幅 $1/\pi$），只是奇对称：$t\to0^{+}$ 时向上冲、$t\to2\pi^{-}$ 时向下冲，动画里 8 项部分和画出的正是这一对尖峰。（把矢量球的初始方向从 $+x$ 改成 $+y$，同一套装置画出的就是 $\sum a_n\cos nx$ 的余弦版本。）

几点观察：

- 方波只含奇次谐波；脉冲**所有次数都在**，偶次项不消失。
- 场景当前取到 $N=8$ 项（原先 4 项）：等幅谱让尖峰大致随项数成比例变高 —— 部分和峰值从 $N=4$ 的 $\approx3.23$ 涨到 $N=8$ 的 $\approx6.14$，乘显示尺度 $10/\pi$ 后即 $\approx10.3\to19.6$；项数越多峰越尖，但永远消不掉。
- 部分和永远"不平"：等幅谱意味着每一项都不衰减，所以不管取多少项，$t=0$ 附近的尖峰都留着。
- 这也是为什么短促的信号（脉冲、敲击、闪电）听起来/看起来"什么都含"：它的频谱是平的。

## 设计交互场景

- 触发系统：3D场景交互所需的触发系统。

### 实体

- PulseFourierPhasors：傅立叶旋转矢量链。组内 `PulseSphere[i]`(i=0..7) 与 `PulseSphere8` 共 9 个节点球
  （y=1.5，半径 0.006，x = −0.5 + (0.1/π)·i，即 x = −0.5、−0.46817、−0.43634、−0.40451、−0.37268、
  −0.34085、−0.30901、−0.27718、−0.24535）；
  节点**等间距**，间距全部是 0.1/π —— 这正是"等幅谱"的几何体现（方波/锯齿波/三角波的节点间距是递减的）；
  `PulseCircle[i]`(i=0..7) 是 8 个振幅圆（半径 = 10/π，八项完全相等，即等幅系数 $1/\pi$ 的 10 倍显示尺度），
  圆心落在第 i 个节点上，第 i 个圆就是第 i+1 个节点的公转轨迹；第 n 个节点绕第 n−1 个节点公转，转 1/2/…/8 圈，方向全部相同（系数全同号）。
- PulseConnectLine：绿色折线，穿过 PulseSphere0…PulseSphere8，把矢量链节点依次连起来（静止时是一条**等间距**的振幅标尺）。
- PulseConnectLinePen：红色细线，连接链末端 PulseSphere8 与描点 PulseSpherePen；其高度即当前部分和。
- PulseSpherePen：红色小球（r=0.01，起点 (0,1.5,0)），链条末端的“画笔”，沿 PulseSineY 行走，把部分和画成波形。
- PulseSineY：x=0 的竖直参数曲线，opacity 0（不可见），仅作 MoveAlong 的轨迹模板，不参与显示。
- PulseSineWave：可见波形，x=10t，y=(10/π)(sin t + sin2t + … + sin8t)，即等幅谱的 8 项部分和曲线；
  触发时由 EntityMesh 扫相位重绘 —— 能明显看到 t=0 附近的尖峰（脉冲），以及这是"任何有限项都消不掉"的振荡。
- PulseTextRun：“运行”按钮（Text，kinematic），初始显示，点击后隐藏并启动整段动画。
- PulseTextBack：“返回”按钮（Text，kinematic），始终显示，点击后回到《1 傅立叶级数.md》。

```phymodel

Group(name: "PulseFourierPhasors", position: (0, 0, 0)) {
    Repeat(8) { i in
        CAD()
        .name("PulseSphere[i]")
        .mesh(commands: [
            "DEF sphere = SOLID_FORMULA 0,0,0 (x/0.006)^2+(y/0.006)^2+(z/0.006)^2-1=0",
        ])
        .material(red: 0.67, green: 0.32, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
        .position(x: -0.5 + 0.1/pi * ((i >= 1 ? 1 : 0) + (i >= 2 ? 1 : 0) + (i >= 3 ? 1 : 0) + (i >= 4 ? 1 : 0) + (i >= 5 ? 1 : 0) + (i >= 6 ? 1 : 0) + (i >= 7 ? 1 : 0)), y: 1.5, z: 0.0)
    }
    CAD()
    .name("PulseSphere8")
    .mesh(commands: [
        "DEF sphere = SOLID_FORMULA 0,0,0 (x/0.006)^2+(y/0.006)^2+(z/0.006)^2-1=0",
    ])
    .material(red: 0.67, green: 0.32, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
    .position(x: -0.5 + 0.1/pi * 8, y: 1.5, z: 0.0)
    .trail(style: .line, lifeSpan: 3.0, size: 0.002, color: [1.0, 0.1, 0.2], opacity: 0.8)
    Repeat(8) { i in
        Graph()
        .name("PulseCircle[i]")
        .mesh(x: "10/pi*cos(t)", y: "10/pi*sin(t)", z: "0", t: "[0,2*pi]", radius: 0.002)
        .material(red: 0.46, green: 0.2, blue: 1.0, opacity: 1, roughness: 0.5, metallic: 0.8)
        .position(x: -0.5 + 0.1/pi * ((i >= 1 ? 1 : 0) + (i >= 2 ? 1 : 0) + (i >= 3 ? 1 : 0) + (i >= 4 ? 1 : 0) + (i >= 5 ? 1 : 0) + (i >= 6 ? 1 : 0) + (i >= 7 ? 1 : 0)), y: 1.5, z: 0.0)
    }
}
```

```phymodel

Behavior()
.name("tap_PulseTextRun")
.trigger{
    Tap(){
        objects: ["PulseTextRun"]
    }
}
.actions{

    Hide(0){
        objects: ["PulseTextRun"]
        motionType: .scale
        duration: 0.5
    }
    // ---------- id=1：播放前瞬时复位（并行） ----------
    //   范围选择 + index：等价于原来的 9 个逐球 Transform，公式与 Group 内 .position(...) 同源
    //   （duration=0 时 translation 是绝对位姿，故必须与声明位置保持一致）
    Transform(1){
        objects: ["PulseSphere[0..8]"],
```
